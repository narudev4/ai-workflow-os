# Decision 0003: まず1案件で実験する

## Status

Accepted

## Date

2026-08-19

## Decision

最初から全案件・全社ディレクトリを移行せず、既存案件1件で GitHub正本 -> Sheets表示 のループを試す。

## Reason

実際の案件で回すことで、必要な列、足りないテンプレート、人間判断が必要な地点が分かる。最初から全体最適を設計すると、抽象化が先行して使われない仕組みになるリスクが高い。

## Consequences

- 初回実験の結果を `experiments/` に残す
- テンプレートは実験後に更新する
- 全社ディレクトリ整理は、1案件の実体験を踏まえて行う
